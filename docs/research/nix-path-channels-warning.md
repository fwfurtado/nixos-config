# Missing root channels in `NIX_PATH`

On this host, `NIX_PATH=nixpkgs=flake:nixpkgs:/nix/var/nix/profiles/per-user/root/channels`, and the last directory does not exist. The `nixpkgs=flake:nixpkgs` entry is a separate named search-path entry; its registry lookup can succeed even when the unnamed channel fallback emits `Nix search path entry ... does not exist, ignoring`. This warning does not mean that the package or system build has failed. [Nix manual: `NIX_PATH`](https://nix.dev/manual/nix/2.34/command-ref/env-common.html#env-NIX_PATH), [Nix evaluator's missing-path warning](https://github.com/NixOS/nix/blob/04bce65df7173deaacedc8fbefb6919231548f98/src/libexpr/eval.cc#L3349-L3413).

The pinned NixOS flake integration defaults to `nixpkgs=flake:nixpkgs` plus the root-channel directory when `nix.channel.enable` is true. The mini-PC configuration now overrides `nix.nixPath` with only `nixpkgs=flake:nixpkgs`; its new generation has been built but not activated. The channel module exports `nix.nixPath` as the session's `NIX_PATH`. [Pinned nixpkgs flake integration](https://github.com/NixOS/nixpkgs/blob/d4f25a3e562008648d45bcf2d70bcc7422cad84e/nixos/modules/misc/nixpkgs-flake.nix#L40-L109), [pinned channel module](https://github.com/NixOS/nixpkgs/blob/d4f25a3e562008648d45bcf2d70bcc7422cad84e/nixos/modules/config/nix-channel.nix#L27-L99).

## Options

- For a single invocation: `NIX_PATH='nixpkgs=flake:nixpkgs' make minipc-build`. This preserves the registry-backed lookup but removes the nonexistent channel fallback for that command only. Preserve other entries if they are actually needed. The same expression was verified locally with `nix eval` without the missing-channel warning. [Nix manual: search path](https://nix.dev/manual/nix/2.34/command-ref/env-common.html#env-NIX_PATH).
- Declaratively, the mini-PC now sets `nix.nixPath = [ "nixpkgs=flake:nixpkgs" ];` in `hosts/minipc/default.nix`. After activation, start a new login session. This removes fallback searches for other channel names without disabling the `nix-channel` program. [Pinned option and session export](https://github.com/NixOS/nixpkgs/blob/d4f25a3e562008648d45bcf2d70bcc7422cad84e/nixos/modules/config/nix-channel.nix#L45-L99), [pinned flake default](https://github.com/NixOS/nixpkgs/blob/d4f25a3e562008648d45bcf2d70bcc7422cad84e/nixos/modules/misc/nixpkgs-flake.nix#L99-L109).
- `nix.channel.enable = false;` also omits the fallback, but removes channel integration/command and does not delete existing channel state: use it only if channels are deliberately retired. Setting only `nix.settings.nix-path` does not remove a missing entry from an already exported `NIX_PATH`. [Pinned channel module](https://github.com/NixOS/nixpkgs/blob/d4f25a3e562008648d45bcf2d70bcc7422cad84e/nixos/modules/config/nix-channel.nix#L27-L42), [Nix config precedence](https://nix.dev/manual/nix/2.34/command-ref/conf-file.html#conf-nix-path).

Do not create an empty root-channel directory just to hide the warning: that obscures a stale search-path entry instead of fixing its source.
